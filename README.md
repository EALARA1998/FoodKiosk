# FoodKiosk

Full-stack food ordering application built with Next.js, focused on performance, scalability, and modern frontend architecture.

The application simulates a digital food kiosk, allowing users to browse products, manage orders, and interact with a responsive and user-friendly interface.

## Features
- Product listing and order management
- Global state management for cart and orders
- Data fetching with caching and revalidation
- Image handling and optimization
- Fully responsive UI
- Schema validation for safer data handling

## Tech Stack
- Frontend: Next.js, React, TypeScript
- Styling: Tailwind CSS
- State Management: Zustand
- Data Fetching: SWR
- Validation: Zod
- Database ORM: Prisma
- Images: Cloudinary
- Notifications: React Toastify
